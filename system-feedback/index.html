        How to read this

        Aligned
        Matches Figma: names, properties, tokens, looks, accessibility and behaviour.
        Drifted
        Works for people, but names, properties or tokens differ from Figma.
        Broken
        Something people would notice: it looks different, fails an accessibility check, has no focus indicator or doesn't render.
        Not built
        In Figma, with no Storybook component of the same name.
        Parity
        Share of checks passed across the Figma components. A warning counts as half; not built counts as zero.
        Severity
        Critical blocks people from using the component. Serious makes it very hard. Moderate makes it harder. Minor is an annoyance.

        Accessibility results come from axe-core (WCAG 2.2 AA) on each rendered story, keyboard and touch-target probes, and a text contrast check on Figma's own token values for every brand. Automated checks find about a third of issues, so keep manual screen reader and keyboard reviews.
