      Connect GitHub

      Checks run on GitHub, so this browser needs a key to start them. Reading reports doesn't need one.

      1. Open GitHub's new token page and name the token, for example "Atom parity".
      2. Under Repository access, choose Only select repositories and pick atom-parity.
      3. Under Permissions, add Actions and set it to Read and write. Generate the token and copy it.

      The key stays in this browser only.
